# SubtitrariApp (subtitle-burner)

Desktop app that automatically transcribes speech from a video,
optionally translates it, and burns clean, balanced subtitles
directly into the video file. Built for non-technical users:
select a video, click two buttons, done.

- Speech recognition: Faster-Whisper (runs locally, no cloud)
- Automatic language detection + optional translation
- Subtitle rows limited and balanced automatically (portrait and
  landscape video supported)
- Built-in editor to review and correct subtitles before burning
- Automatic updates

## Download

Get the latest installer from the
[Releases page](https://github.com/amuscalu/subtitle-burner/releases/latest):
**SubtitrariApp_Setup.exe** — double-click, Next, Install.

Requires Windows 10/11 (64-bit) and an internet connection on first
run (the AI model, ~1.5 GB, is downloaded once).
